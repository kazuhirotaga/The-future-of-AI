# 眠らない同僚

**24時間365日、影で働き続けるAIエージェントの正体**

---

## この本について

多くの人にとって、AIとは「質問すると答えてくれるもの」だ。
検索窓の延長線上にある、賢い自動販売機。呼べば応じ、黙れば眠る。

だが、その理解はすでに時代遅れになりつつある。

いま静かに起きているのは、AIが**呼ばれてから答える存在**から、
**頼まれた後もひとりで働き続ける存在**へと変わる、という転換だ。

人間が眠っている間も、休日も、年末年始も、それは動いている。
疲れず、飽きず、待たず、しかも何十体にも分身して。

本書は、この「影の労働」の正体を解剖する。
なぜ多くの人がまだ気づいていないのか。
気づいたとき、仕事と組織と責任のかたちは、どう変わるのか。

## 本書の立場について

本書は、AIエージェントを賛美も断罪もしない。

「便利になる」という話でも、「仕事が奪われる」という話でもない。
起きているのは、**労働の可用性が変わる**という、もっと地味で、もっと根本的な変化だ。

地味な変化ほど、気づいたときには引き返せない。
だから、いま見ておく価値がある。
